# Leon Template (One Page)

Responsive one-page agency landing page built with **HTML** and **CSS**.

## Features
- Clean one-page layout (Landing / Features / Services / Portfolio / About / Contact)
- Responsive design
- Font Awesome icons + Google Fonts

## Tech Stack
- HTML5
- CSS3
- Normalize.css
- Font Awesome
